# Mastering Genkit

A series of open books that teach you how to build production-ready AI applications with [Genkit](https://genkit.dev), one language at a time.

Every edition follows the same path, from a first `generate` call to agents running in production, and every chapter ships with runnable example code written in that edition's language.

## What the books cover

1. Introduction to Genkit
2. Understanding Genkit architecture
3. Setting up your development environment
4. Mastering AI generation
5. Structured output
6. Building flows
7. Streaming
8. Tools
9. Model Context Protocol (MCP)
10. Retrieval-Augmented Generation (RAG)
11. Evaluations
12. Agents
13. Monitoring and observability
14. Deployment
15. Client integration
16. Resources

## Formats

Each edition is published as a web book, PDF, and EPUB. Downloads are attached to the releases of each repository.
